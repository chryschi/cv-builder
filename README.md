# [CV-Builder](https://cv-builder-chryschi.netlify.app/)

_(for a description in german see below)_

_This is a project included in [The Odin Project](https://www.theodinproject.com/) online course._

The CV-Builder lets you fill in a printable and modern looking CV and is currently available in german only.

## Challenges

- Let print preview show the content of the web preview without additional margins and paddings or background content.

## Features

- There are many sections to choose from (e.g. Career, ), that can be toggled on and off.
- Individual bullet points can be toggled on and off.

## Used Technology

This project was built with Vite, React, HTML/CSS/JS and deployed with Netlify.

The project logo was created with Inkscape.

## Future Features

- english version of CV-Builder
- responsive view
- customizable order of CV sections
- customizable order of bullet points of each section
- save form data in local storage to prevent data loss on page refresh

# CV-Builder (deutsche Beschreibung)

_Das ist ein Projekt, das im Onlinekurs [The Odin Project](https://www.theodinproject.com/) enthalten ist._

Mit dem CV-Builder lässt sich ein moderner, minimalistischer Lebenslauf ausfüllen und ausdrucken. Zurzeit existiert die Web-Applikation nur auf Deutsch.

## Herausforderungen

- Alle überflüßigen Abstände und Paddings und Hintergrundelemente in der Druckansicht entfernen, sodass sie mit der Ansicht in der App übereinstimmt.

## Features

- Verschiedene Abschnitte, wie zum Beispiel "Karriere" oder "Kenntnisse", lassen sich ein- und ausblenden.
- Auch einzelne Stichpunkte können ein- und ausgeblendet werden.

## Verwendete Technologien

Dieses Projekt wurde mit Vite, React, HTML/CSS/JS erstellt und mit Netlify online gestellt.

Das Logo wurde mit Inkscape erstellt.

## Zukünftige Features

- Englische Version des CV-Builders
- Responsive Ansicht
- Verstellbare Reihenfolge der Abschnitte
- Verstellbare Reihenfolge der Stichpunkte
- Speichern der Formulardaten im lokalen Speicher des Browsers um erneutes Eintippen nach Neuladen der Website zu vermeiden
